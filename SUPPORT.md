# Getting help

Thanks for playing Primordial Rise.

- **Found a bug?** Use the [bug report form](https://github.com/Primordial-Rise/.github/issues/new?template=bug_report.yml).
- **Played a session and want to tell us how it felt?** Use the
  [playtest feedback form](https://github.com/Primordial-Rise/.github/issues/new?template=playtest_feedback.yml).
  Short notes are welcome.
- **Have an idea?** Use the [feature idea form](https://github.com/Primordial-Rise/.github/issues/new?template=feature_idea.yml).
- **A security problem?** Do not post it publicly: follow the [security policy](SECURITY.md).

Before you post, please check that nobody has reported the same thing already, and leave
out passwords, tokens and other private details.

The game's source code is private, so these forms are the way to reach the team.
Response times vary: Primordial Rise is made by a very small team.
